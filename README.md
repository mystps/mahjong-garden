# Garden Mahjong Solitaire

A free, easy mahjong solitaire with big, colorful garden and forest tiles.
Made for older players and for everyone who likes a calm game.

**Play:** https://mystps.github.io/mahjong-garden/

## Features

- Big tiles and almost no text, so it is easy to understand at a glance
- Made for phones held upright, also works on tablets and computers
- Three board sizes: small, medium and large
- Every game can be won: boards are generated so a full solution always exists
- Hint, undo and shuffle buttons
- Works offline once opened
- No ads, no accounts, no tracking

## Install on your phone

Open the game link in your browser, then use the browser menu:

- Android (Chrome): "Install app" or "Add to Home screen"
- iPhone (Safari): Share, then "Add to Home Screen"
